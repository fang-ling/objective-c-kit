# ``ObjectiveCKit``

Gain low-level access to the Objective-C runtime and the Objective-C root types.

## Overview

The ``ObjectiveCKit`` module APIs define the base of the Objective-C language.
These APIs include:

- Types such as the ``ObjectiveCObject`` class and the ``ObjectiveCObject``
  protocol that provide the root functionality of most Objective-C classes
- Functions and data structures that comprise the Objective-C runtime, which
  provides support for the dynamic properties of the Objective-C language

You typically don't need to use this module directly.
